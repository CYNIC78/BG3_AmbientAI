# AmbientAI b04.3.25 — «Фамильяр: характер в дрейфе»

Файл: `AmbientAI_b04_3_25_FamiliarCharm.pak` · md5 `83cf68372165165788db2aa42a2bdb6f`
База — 04.3.24 (`previous/`).

## Что изменилось в движении

Раньше он прыгал в случайную точку вокруг ГГ — работало, но читалось как шум. Теперь у каждого
фамильяра **своя орбита**:

* шаг 35–75° по кругу (радиус 2.2–3.6 м), то есть он именно **облетает** партию;
* разворот примерно в 20% случаев — «передумал»;
* иногда близкий проход (1.8–2.1 м) — подлетел, посмотрел, отлетел;
* после каждого перелёта **поворачивается к ГГ** (`Osi.LookAtEntity`) — мелочь, но из «объекта,
  который двигается» он превращается в «существо, которое на тебя косится»;
* неудачные попытки (занятое место) больше не крутят орбиту — раньше из-за этого траектория
  становилась рваной.

Правила прежние: не в бою, не при врагах, не в диалоге, ГГ стоит, не ближе 1.5 м к людям.

## Про настоящие анимации (крутануться вокруг оси и т.п.)

Тут честно: клипы фамильяра лежат в анимационном банке игры, веб их имена не знает, а перебор
101k записей — это то, для чего у нас есть `!ambient_anim_find`. Поэтому два шага:

```
!ambient_anim_find imp            сканирует банк Animation на имена со "imp" (кусками по 6 мс)
!ambient_anim_find familiar       если по "imp" пусто - пробуем "familiar"
```

Что найдётся — можно **сразу проверить без новой сборки**:

```
!ambient_familiars anim <полное имя ресурса>    проиграть 9 секунд на всех фамильярах
!ambient_familiars anim off                     остановить
```

Если имя подойдёт (например что-то вроде спина/флипа), я впишу его в дрейф: «иногда вместо
перелёта крутится на месте». Это уже будет настоящая анимация, а не имитация.
