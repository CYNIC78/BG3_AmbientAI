## Как пользоваться

```bash
python3 tools/bg3_catalog.py                       # пересобрать catalog.json/.csv
python3 tools/bg3_catalog.py --only 'type:animationset imp'
grep -i 'drink' bg3_anim_dumps/catalog.csv         # поиск по готовому каталогу
```

catalog.csv колонки: `name;uuid;type;path;skeleton;duration;looping;queries`.
Колонка `queries` показывает, каким запросом запись была найдена — удобно для отладки поиска.
